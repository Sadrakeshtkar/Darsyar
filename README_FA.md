# درس‌یار – نسخه اولیه اندروید

این پوشه یک پروژه منبع Android Studio است، نه APK آماده نصب.

## امکانات موجود در نسخه اولیه
- رابط فارسی راست‌چین با انتخاب پوسته روشن/تیره
- افزودن پارت با درس، مبحث و ساعت یادآوری
- اعلان محلی برای زمان پارت (با مجوز اعلان و در صورت نیاز مجوز آلارم دقیق)
- ثبت گزارش پایان پارت: مدت مطالعه، تعداد تست، صحیح، غلط و نزده
- ذخیره محلی گزارش‌ها و برنامه‌ها
- آمار بازه روزانه/۷ روز اخیر/۳۰ روز اخیر
- تفکیک ساعت و تست بر اساس درس
- تایمر ساده مطالعه
- هدف روزانه ساعت و تست
- شمارنده ثبت آزمون
- خروجی متنی JSON برای پشتیبان‌گیری

## ساخت APK
1. Android Studio را نصب کن.
2. از مسیر File > Open، پوشه DarsYar را انتخاب کن.
3. صبر کن Gradle Sync کامل شود.
4. گوشی اندرویدی را وصل کن یا شبیه‌ساز بساز.
5. از Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کن.

## نکته‌های نسخه اولیه
- نمودار فعلی آخرین هفت گزارش ثبت‌شده را نشان می‌دهد؛ در نسخه بعدی می‌توان نمودار روزبه‌روز تقویمی و فیلتر دقیق تاریخ را کامل‌تر کرد.
- فرم آزمون در این نسخه شمارنده ثبت دارد و هنوز بانک کامل نتایج آزمون/تحلیل درس‌به‌درس نیست.
- پشتیبان‌گیری در این نسخه از طریق اشتراک‌گذاری متن JSON انجام می‌شود؛ بازیابی خودکار فایل هنوز اضافه نشده است.
- تایمر فعلی هنگام خروج از صفحه/بسته‌شدن برنامه در پس‌زمینه تضمین‌شده نیست.
- برای اعلان‌ها، مجوز اعلان را در اندروید تأیید کن. برخی گوشی‌ها برای اعلان دقیق به مجوز جداگانه آلارم نیاز دارند.
- قبل از استفاده جدی، پروژه باید در Android Studio روی دستگاه واقعی Build و آزمایش شود.
